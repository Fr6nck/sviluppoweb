MyHouse design system

The literal implementation of document 19. Every value on this page comes from styles/tokens.css; nothing is hard-coded twice.

The influence is Apple's philosophy — restraint, whitespace, one clear action, typography carrying the hierarchy — not Apple's appearance. Three things make it MyHouse rather than generic: a warm neutral instead of a cool grey, a serif at display sizes, and a deep cypress green where every other tool uses blue.

Colour

Warm neutrals, one brand ramp, one restrained accent, five semantic roles. Every text pairing is at least 4.5:1. Support mode has a colour used nowhere else, so an impersonation banner can never be mistaken for anything.

Typography

Fraunces at display sizes, Inter for everything else, monospace for anything a guest transcribes into a keypad. Measure is capped at 68 characters, 60 on the guest guide.

Codes are always monospace with tabular numerals and wide tracking. A guest is copying them into a keypad one character at a time, often in bad light.

Spacing

A 4px base. The admin console uses the same scale one step tighter — the density difference between the two surfaces is a multiplier, not a second system.

Four levels, all subtle, all tinted with the ink colour rather than pure black so shadows stay warm. Elevation communicates layering, never decoration — a card does not lift on hover unless it is draggable.

Motion

Entering is slower than leaving. Nothing animates opacity alone. No loops except a spinner, and only after 400ms of waiting. prefers-reduced-motion collapses every duration at the token level, so no component can forget it.

Buttons

One primary per screen. Minimum touch target 44×44, achieved with padding rather than by growing the visible control. Loading replaces the label but holds the width, so nothing reflows.

Inputs

Label above, always visible — never a placeholder as a label. 44px minimum height, 16px minimum font size so iOS does not zoom. Focus is a 2px ring, never outline:none.
