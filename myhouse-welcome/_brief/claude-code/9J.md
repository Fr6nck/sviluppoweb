Modello: **Sonnet**. Lavora sul progetto attuale, non ricominciare. Fai SOLO questo; nessuna migrazione (le palette sono nel codice). ## 1 · La palette
In `Palette::P`, prima di `grafite`, aggiungi (valori già controllati: tutte le coppie ≥ 5,7:1, la maggior parte oltre 10:1):
```php
'monocromo' => [
    'label' => 'Bianco e nero',
    'scuro'  => ['bg' => '#f5f5f4', 'surface' => '#ffffff', 'sunk' => '#ebebea', 'ink' => '#111111', 'muted' => '#5c5c5c', 'line' => '#dcdcdc', 'accent' => '#111111', 'on_accent' => '#ffffff'],
    'chiaro' => ['bg' => '#0d0d0d', 'surface' => '#1c1c1c', 'sunk' => '#151515', 'ink' => '#f2f2f2', 'muted' => '#a3a3a3', 'line' => '#2e2e2e', 'accent' => '#f2f2f2', 'on_accent' => '#0d0d0d'],
    'tiles' => ['#1c1c1c', '#3d3d3d', '#666666', '#d9d9d9'], 'tile_ink' => ['#ffffff', '#ffffff', '#ffffff', '#111111'],
],
```
Le due versioni si scelgono come per le altre palette: **chiara** (fondo bianco, testo nero) e **scura** (fondo nero, testo bianco). Disponibile in tutti i piani come le altre palette (controlla se Aspetto è limitato da `Entitlements`: segui la stessa regola).

## 2 · Rifiniture perché sia davvero monocromatica
Dal mockup si vedono colori che non vengono dalla palette:
- il bollino **«DEMO»** giallo e la pillola **«Ti accogliamo di persona»** azzurra (e le altre pillole/etichette di stato, gli indicatori «acceso adesso», i badge delle novità nella guida): devono usare le variabili della palette (`--sunk`, `--ink`, `--accent`, `--muted`), non colori fissi. Cerca nei CSS della guida (`assets/…guida…css`, `views/guest/`) i colori esadecimali scritti a mano e sostituiscili con le variabili; i colori fissi restano solo dove servono per significato (verde «aperto adesso», rosso «emergenze»), e in quel caso valgono per tutte le palette.
- Nella versione **scura** il primo riquadro (`#1c1c1c`) si stacca poco dal fondo (`#0d0d0d`): per la palette `monocromo` aggiungi ai riquadri un bordo di 1 px `--line` (solo per questa palette, con una classe `palette-monocromo` sul `<html>` o una variabile `--tile-border`).
- Opzione nuova in Aspetto, visibile solo con «Bianco e nero»: casella **«Foto in bianco e nero»** (di serie spenta). Accesa: `filter: grayscale(1)` su copertina, foto delle sezioni, foto dei luoghi e foto profilo nella guida (non nel pannello). Salvata in `properties` (`photos_bw` 0/1, se serve una colonna fai la migrazione numero successivo) ed entra nell'istantanea pubblicata.
